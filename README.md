# Image Converter for OLED / LCD Screens

A general-purpose web utility designed to convert static images into custom C-style byte arrays for various monochrome OLED/LCD screens (like SSD1306, Nokia 5110, PCD8544).

🚀 **[Buka Live Image Converter di sini!](https://triwahyu45.github.io/Image-Converter-for-OLED-LCD/)**

---

## 🌟 Features

*   **Multiple LCD Profiles**: Choose presets for SSD1306 (128x64) or Nokia 5110 (84x48) screens.
*   **Orientation Formats**: Supports both Horizontal (Page) and Vertical image scanning directions.
*   **Invert Colors**: Toggle to swap black and white pixels easily.
*   **Responsive Design**: A clean, single-page application tool ready to use immediately without any software installation.\n
